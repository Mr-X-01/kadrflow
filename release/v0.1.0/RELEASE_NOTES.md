# KadrFlow 0.1.0

Первый самостоятельный релиз KadrFlow: нарезка видео, рекомендации YouTube, игровые композиции, логотипы, рекламные вставки и публикация клипов.

Для Windows 10/11 x64 скачайте `KadrFlow-0.1.0-Setup-windows-x64.exe`. Он установит
программу для текущего пользователя и создаст ярлык на рабочем столе.
Если Microsoft WebView2 ещё не установлен, установщику потребуется интернет.
Для переносного запуска доступен ZIP: распакуйте его целиком и запустите
`KadrFlow.exe` из папки `KadrFlow`.

Исправлен выбор русских субтитров при наличии русской и английской дорожек.

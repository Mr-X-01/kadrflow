# Установка KadrFlow на Mac

Перетащите `KadrFlow.app` в папку `Applications` и откройте приложение.

Сборка подписана временной подписью без нотариального заверения Apple. Если macOS
блокирует первый запуск, откройте «Системные настройки» → «Конфиденциальность и
безопасность» и разрешите запуск KadrFlow.

Если окно не появилось, запустите приложение из Terminal:

```sh
/Applications/KadrFlow.app/Contents/MacOS/KadrFlow
```

Диагностический журнал находится в `~/Library/Application Support/KadrFlow/app.log`.

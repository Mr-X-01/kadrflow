# KadrFlow на Windows

## Локальный сайт в браузере

Установите Python 3.12 x64. Скачайте исходники KadrFlow, распакуйте архив,
откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 run_web.py
```

Первый запуск создаст `.venv-web`, установит зависимости и откроет
`http://127.0.0.1:8765/`. Для другого порта используйте
`py -3.12 run_web.py --port 8770`. Терминал нужно оставить открытым;
остановка — Ctrl+C. Проекты, клипы и модель хранятся в `data` или в папке,
заданной через `KADRFLOW_DATA`.

Этот режим не требует BAT-файла, EXE приложения и WebView2. Нужны Python,
FFmpeg (предоставляется Python-пакетом) и соединение с интернетом для установки
зависимостей, поиска видео и загрузки модели речи. Проверка на реальном Windows
ещё не проводилась.

## Настольная сборка

Исходники также содержат сценарий сборки отдельного окна:

```powershell
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```

Сценарий создаёт `dist\KadrFlow\KadrFlow.exe`. Для этого режима может
потребоваться WebView2 Runtime. GitHub Actions собирает Windows ZIP и проверяет
локальный HTTP API. Готовые сборки публикуются отдельно в Releases после проверки.

Данные настольной сборки: `%APPDATA%\KadrFlow`; скачанные клипы по умолчанию:
`%USERPROFILE%\Downloads\KadrFlow`.
